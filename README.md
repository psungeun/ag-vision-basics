## 📌 Overview
이 프로젝트는 학부 '영상식물학 및 표현체학(Plant Phenotyping and Imaging)' 수업에서 다룬 핵심 알고리즘들을 바탕으로, 실제 농업 현장(스마트팜, 자율주행 농기계 등)에 적용할 수 있는 이미지 처리 기술들을 테스트하고 기록한 공간입니다.

## 🛠 Contents (작업 예정)
- [ ] **Tractor Object Matching:** SIFT & RANSAC 알고리즘을 이용한 자율주행 농기계(John Deere) 객체 인식 테스트
- [ ] **Leaf Area Segmentation:** GrabCut 알고리즘을 활용한 복잡한 배경 속 작물 잎 분할 및 면적 추출
- [ ] **Image Preprocessing:** 온실/노지 환경의 불규칙한 조명 보정을 위한 영상 전처리 (Gaussian Blur, Gamma Correction)
